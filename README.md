# 📡 Toffee Live TV Automation & M3U Playlist

> Automated M3U and JSON playlist generator for Toffee Live TV channels, running securely via GitHub Actions.

---

## ✨ Features
* **Auto-Discovery:** Automatically scans Toffee dynamic rail APIs to extract active live channels.
* **Fresh Streams:** Generates real-time playback tokens and stream URLs on every run.
* **Multi-Format Support:** Exports channels into both clean `toffee_channels.m3u` and `toffee_channels.json` formats.
* **Automated Workflow:** Runs via GitHub Actions automatically every 6 hours to keep links alive.
